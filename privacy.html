プライバシーポリシー

subsc（個人用の家計アプリ）　制定日: 2026年11月10日

1. このアプリについて

subsc は、開発者本人が自分のパソコンの中だけで使う家計アプリです。インターネット上のサーバーでは動いておらず、一般の利用者への提供はしていません。

2. 取得する情報

Google アカウントと連携した場合、Gmail の読み取り専用の権限（https://www.googleapis.com/auth/gmail.readonly）で、次のメールだけを読み取ります。

  • クレジットカード会社からの利用通知（利用日・金額・利用先）
  • サブスクリプションなどの領収書（日付・金額・サービス名）
  • 通販サイトの注文確認メール（日付・合計金額）

上記以外のメールの内容は保存しません。

3. 情報の使い方と保存場所

  • 読み取った情報は、支出の集計・分類・サブスクの管理のためだけに使います。
  • 情報と、Google から発行されるアクセス用のトークンは、アプリを動かしているパソコンの中のデータベースファイルにだけ保存します。
  • 開発者のサーバーや第三者のサービスには送信しません。広告・分析・機械学習の学習には使いません。
  • メールの送信・削除・変更は行いません。

4. 第三者への提供

取得した情報を第三者に提供・販売することはありません。

5. Google API の利用について

Google API から受け取った情報の利用と他のアプリへの転送は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

6. 連携の解除とデータの削除

  • Google アカウントの サードパーティのアクセス の画面から、いつでもこのアプリのアクセスを取り消せます。アプリの設定画面からも連携を解除できます。
  • 保存した情報は、アプリのデータベースファイルを削除するとすべて消えます。

7. お問い合わせ

このポリシーについてのお問い合わせは、GitHub の Issues からお願いします。
